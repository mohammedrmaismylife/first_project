
Git & GitHub Basic Workflow Guide

1. Edit (Modify):
   Modify or create files using your code editor (e.g., VS Code or nano). Git detects these changes as 'modified' or 'untracked'.

2. git add <file>:
   Moves modified or untracked files to the staging area, marking them ready to be committed.
   Example: git add README.md  (or 'git add .' for all files)

3. git commit -m "message":
   Saves your staged changes into the local Git history with a brief message explaining what you did.
   Example: git commit -m "Update README"

4. git push --set-upstream origin main:
   Uploads your local commits to your remote GitHub repository and links your local branch to the remote 'main' branch.
